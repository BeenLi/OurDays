# Decision 0001 — 「纸上双线」：纸/墨色底 + 固定身份色

- **日期**：2026-10-21　**状态**：Accepted，#3 已落地
- **范围**：全部页面

## 背景
1.4 之前的 UI 是系统默认样式，日历里"谁的日程"靠颜色标签区分，没有固定的身份语言；用户想要一个有辨识度、两个人各占一条线的视觉。

## 决策
1. 底色纸色 `#F6F3EE`，文字/主按钮/共同日程/AccentColor 用墨色 `#1E2233`。
2. 身份色固定：**我 = 青色** `#1F7A84`（淡色 `#E1F1F2`），**对方 = 珊瑚色** `#C93E4E`（淡色 `#FBE6E8`）。每个头像都带身份色描边，日视图两条泳道、周条圆点、评论气泡、邀请票据都沿用这两种颜色。
3. 标题与数字用衬线字体。
4. 主题常量集中在 `Views/DesignSystem.swift`，页面只引用，不各自定义颜色。

## 备选与理由
- (否决) 让用户自选颜色：两人制里固定"我青色、对方珊瑚"比可配置更容易一眼读懂，也省去同步颜色偏好。
- (否决) 保留系统样式只换强调色：无法表达"两条线"的核心隐喻。

## 影响
- 设置页标签改名「我们」；代码里的 `settingsTitle` 字符串键保留给测试。
- 宣传片、官网、README 截图都按这套配色制作（见 [docs-and-site](../../docs-and-site/)）。
