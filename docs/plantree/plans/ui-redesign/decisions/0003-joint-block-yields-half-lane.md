# Decision 0003 — 共同日程块与单方事件重叠时让出一半泳道

- **日期**：2026-10-21　**状态**：Accepted，#5 已落地
- **范围**：日视图布局

## 背景
#3 之后共同日程块横跨两条泳道、画在泳道事件之上，对方同一时段的单方事件被整个盖住，看不见。

## 决策
按时间判断共同块与哪一侧的泳道事件重叠：重叠的那一侧，共同块让出泳道**外侧的一半**，该泳道事件收窄到那一半（我的在左半，对方的在右半），两者并排可见；没有重叠时共同块仍横跨两条泳道。

## 备选与理由
- (否决) 共同块永远只占中间一段：没有重叠时浪费宽度，也削弱"共同"的视觉。
- (否决) 单方事件画在共同块之上：时间短的单方事件会把共同块切碎。

## 影响
- 宣传片里的共同块故意不让位（用户要求横跨整宽），所以宣传片和 App 在这一点上不一致，属已知差异。
